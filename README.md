# فاکتور آنلاین — ver1.1

نسخه توسعه‌یافته فاکتور آنلاین فارسی، مناسب GitHub Pages و بسته‌بندی اندروید.

## انتشار روی GitHub Pages
1. محتوای این پوشه را در ریشه یک مخزن GitHub بارگذاری کنید.
2. از مسیر Settings → Pages، گزینه Deploy from a branch را انتخاب کنید.
3. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.
4. پس از انتشار، سایت را در گوشی باز کنید و در مرورگر گزینه Add to Home screen را بزنید.

## امکانات محلی این نسخه
- حداکثر سه پروفایل فروشنده و فاکتورهای شماره‌دار.
- دفترچه مشتریان و انتخاب مشتری ذخیره‌شده.
- بانک کالا و خدمات با قیمت، واحد و موجودی ثبت‌شده.
- صدور فاکتور و پیش‌فاکتور پایه، تخفیف، مالیات قابل تنظیم و وضعیت پرداخت.
- ثبت دریافت‌های جداگانه، هزینه‌ها، گزارش فروش و مانده مطالبات.
- خروجی گزارش CSV، PDF/چاپ، تصویر و اشتراک‌گذاری از گوشی.
- پشتیبان‌گیری و بازیابی اطلاعات برنامه، شامل داده‌های افزوده نسخه ۱.۱.
- قفل محلی با PIN هش‌شده و قفل خودکار اختیاری.
- ثبت رویدادهای اصلی در سوابق فعالیت.

## نکات مهم و محدودیت‌ها
- داده‌ها روی همان دستگاه/مرورگر نگهداری می‌شوند. نسخه فعلی همگام‌سازی ابری یا انتقال خودکار بین دستگاه‌ها ندارد.
- PIN یک قفل محلی برای جلوگیری از دسترسی اتفاقی است، نه سامانه احراز هویت یا رمزگذاری کامل پایگاه داده. از اطلاعات حساس بانکی غیرضروری در دستگاه مشترک استفاده نکنید.
- پیامک در نسخه پایه برنامه پیامک گوشی را باز می‌کند و ارسال نهایی با تأیید کاربر است. ارسال خودکار پیامک و یادآوری بدهی به پنل پیامکی و سرور امن نیاز دارد.
- اشتراک‌گذاری واتساپ/تلگرام از طریق قابلیت Share گوشی انجام می‌شود؛ ارسال خودکار به حساب‌ها به API مجاز نیاز دارد.
- همگام‌سازی ابری، چندکاربره و سطح دسترسی، ورود بیومتریک بومی، پورسانت، اتصال سامانه مؤدیان و چاپگرهای حرارتی به سرویس یا افزونه بومی و پیکربندی اختصاصی نیاز دارند و در این بسته به‌عنوان اتصال فعال ادعا نمی‌شوند.
- موجودی کالا در این نسخه ثبت و نمایش داده می‌شود؛ گردش انبار کامل و کسر خودکار موجودی هنوز پیاده‌سازی نشده است.
- پیش‌فاکتور در این نسخه با نوع سند مشخص می‌شود؛ گردش تأیید و تبدیل کامل پیش‌فاکتور به فاکتور در نسخه بعدی تکمیل می‌شود.
- فاکتور صادرشده در این برنامه لزوماً فاکتور رسمی مالیاتی نیست؛ برای آن باید الزامات قانونی و اتصال رسمی جداگانه بررسی شود.
- PDF و تصویر برای تولید خروجی ممکن است به اینترنت برای بارگذاری کتابخانه‌های CDN نیاز داشته باشند.

## نگهداری داده نسخه قبلی
شناسه پایگاه داده محلی اصلی حفظ شده است تا داده‌های نسخه اول در همان مرورگر باقی بمانند. برای اطمینان، پیش از ارتقا یک فایل پشتیبان تهیه کنید.
